# Portfólio Pessoal — Isadora Tosi


## Sobre o projeto

Este projeto consiste no desenvolvimento de um portfólio pessoal para apresentar minha trajetória como estudante de Desenvolvimento de Sistemas, minhas habilidades e alguns projetos desenvolvidos durante meus estudos.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5
- GitHub Pages

## Estrutura do projeto

- `index.html`: estrutura e conteúdo do site.
- `css/style.css`: estilos, cores, layouts e animações.
- `img/`: imagens utilizadas no portfólio.

## Funcionamento do projeto

O site possui um menu de navegação que permite acessar as seções de apresentação, sobre mim, habilidades, projetos e contato.

O layout utiliza componentes do Bootstrap para organizar os conteúdos e facilitar a adaptação a diferentes tamanhos de tela.

## Recurso novo

Foi implementado um efeito de animação nos cards de habilidades e projetos.

Ao passar o mouse sobre os cards, eles se deslocam suavemente para cima e recebem uma sombra.

## Como o recurso foi implementado

O efeito foi desenvolvido utilizando CSS, por meio das propriedades `transition`, `transform` e `box-shadow`, aplicadas com o seletor `:hover`.
